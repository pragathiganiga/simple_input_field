# ✏️ Input Field UI – HTML & CSS

A simple and clean **input field design** created using HTML and CSS.  
This mini project focuses on styling form inputs with modern UI, smooth interactions, and responsive layout.

---

## 🎯 Project Overview

This project demonstrates how to create a neat and user-friendly input field using only HTML and CSS.  
It is perfect for beginners learning form styling, placeholders, labels, and responsive input designs.

---

## ✨ Features

- Clean and modern UI  
- Styled input fields  
- Hover and focus effects  
- Fully responsive  
- Minimal and beginner-friendly code  

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**

---

## 📥 How to Use

1. Download or clone the repository.  
2. Open the project folder in your code editor.  
3. Run `index.html` in your browser.  
4. Customize fonts, colors, borders, and animations as needed.
